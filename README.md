# 学習バトルフィールド（gakushu-fps）

小学2年生・小学5年生が、FPS風の訓練ゲームを通じて**国語・算数・英語**を反復学習するためのウェブアプリプロジェクトです。学習内容は学習指導要領を基準に設計し、特に文章理解、解法の再現、漢字記憶、読書習慣の弱さを支援することを目標にしています。

> このリポジトリは開発用の初期基盤です。教材内容とゲーム機能は今後、段階的に実装します。

## 基本方針

| 項目 | 方針 |
|---|---|
| 対象 | 小学2年生・小学5年生 |
| 科目 | 国語・算数・英語 |
| ゲーム表現 | FPS風の訓練場、作戦カード、ドローン、端末、補給箱 |
| 安全設計 | 人体や実在武器を標的にせず、学習対象を選択・解除する表現を使用 |
| 学習サイクル | 読む → 要点を拾う → 解き方を選ぶ → 答える → 手順を再現する |
| 記録 | 子ども別に正答率、再挑戦、弱点、再現性を記録する予定 |

## 技術構成

React 19、TypeScript、Vite、Tailwind CSSを使用したウェブアプリです。ゲーム画面にはBabylon.jsの採用を予定しています。

## ローカル起動

```bash
pnpm install
pnpm dev
```

型検査と本番ビルドは次のコマンドで確認できます。

```bash
pnpm check
pnpm build
```

## 開発ロードマップ

| 段階 | 内容 |
|---|---|
| 1 | プロフィール選択、科目・学年別ミッション、端末内の進捗保存 |
| 2 | 3D訓練場、回答ターゲット、作戦カード、連続正解・再挑戦 |
| 3 | 文章読解の段階表示、解法再現チェック、漢字の想起学習 |
| 4 | 保護者向け弱点レポート、教材追加、学習履歴の分析 |

## 教育設計上の重点

文章を単なる文字列ではなく意味のまとまりとして扱えるように、短い文章の区切り、主語・述語・要点の発見、根拠の選択をゲーム内の索敵行動に置き換えます。算数では答えだけでなく、使った公式・手順・理由を再入力させ、時間を空けた再挑戦によって再現性を確認します。漢字はトレース中心にせず、読み、意味、部品、文中利用、見ないで思い出す活動を組み合わせます。
